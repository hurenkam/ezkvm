# ezkvm

`ezkvm` is a Rust project initialized for iterative development.

## Prerequisites

- Rust toolchain (stable)
- Cargo

## Build

```bash
cargo build
```

## Run

```bash
cargo run
```

## Test

```bash
cargo test
```

## Quality Checks

```bash
cargo fmt --all --check
cargo clippy --all-targets --all-features -- -D warnings
```
