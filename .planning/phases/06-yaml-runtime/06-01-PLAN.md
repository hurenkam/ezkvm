<objective>
Wire the Runtime ↔ ezkvm YAML ↔ Runtime pipeline with typed errors and lossless field
preservation for all v1 device types (RUNT-01–07).

Purpose: YAML-01 and YAML-02 require that every modeled Runtime field survives a round-trip
through the ezkvm YAML schema unchanged. The current parser.rs and builder.rs cover only
Memory, Q35 bus topology, and basic storage skeletons — they silently discard EfiDisk,
TpmState, AudioDevice, SpiceDisplay, RawArgs (root devices) and HostPci and Ivshmem (PCIe
devices), synthesize storage resource IDs without storing paths, and return bare String errors
that violate the typed-error contract from D-01. This plan closes all those gaps in three
tasks.

Output:
- src/config/ezkvm/runtime/error.rs  — new: YamlRuntimeError thiserror enum
- src/config/ezkvm/runtime/parser.rs — extended: all v1 root and PCIe devices; YamlRuntimeError
- src/config/ezkvm/runtime/builder.rs— extended: resource-ID resolution; YamlRuntimeError
- tests/yaml_round_trip.rs           — new: Felucia-108 end-to-end YAML round-trip integration test
</objective>
