# Plan 08.1-03 Summary

## What was done

Completed both tasks in `08.1-03-PLAN.md` end-to-end.

### Task 1
- Added `VirtioScsiSingleDisk` as a first-class merged PCIe + SCSI + storage Runtime device.
- Updated Proxmox import so `scsihw: virtio-scsi-single` creates one `VirtioScsiSingleDisk` per `scsiN` entry, keyed by the Proxmox disk index.
- Assigned PCIe slots `16 + scsiN` for these per-disk devices.
- Updated QEMU emission so each merged device emits its own iothread, controller, drive, and device block with collision-free IDs derived from the `scsiN` index.
- Extended shared SCSI storage emission to take an explicit controller id while preserving byte-identical shared-controller output for `pvscsi` and `virtio-scsi-pci`.
- Added tests covering per-disk importer behavior and 4-instance collision-free commandline emission.

### Task 2
- Added `PcieDeviceTypeSchema::VirtioScsiSingle { resource, index, storage_type }`.
- Wired `VirtioScsiSingleDisk` through runtime->schema parsing, schema->runtime building, and Q35 display formatting.
- Added YAML round-trip coverage for the new schema variant.
- Added a real-corpus round-trip test for `input/zbp-server-mh2/301.conf`, asserting 4 distinct `VirtioScsiSingleDisk` instances preserve slot, index, resource, and storage type.
