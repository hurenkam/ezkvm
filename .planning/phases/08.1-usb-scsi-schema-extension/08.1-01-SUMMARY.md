**USB host passthrough now uses a typed UsbHostIdentity across Proxmox import, ezkvm YAML, Runtime display, and QEMU emission, fixing vendor:product IDs without regressing bus-port handling.**

- Added typed Proxmox import failure for malformed `usbN: host=` values and removed the QEMU emitter panic path.
- Propagated the new USB identity shape through ezkvm YAML schema, Runtime/YAML conversions, Q35 display formatting, and round-trip tests.

## Decisions Made

- Parsed `usb_conf.host` exactly once in `ProxmoxImporter`, mirroring the plan's existing parse-once-at-boundary pattern.
- Used a nested tagged schema enum for YAML so BusPort and VendorProduct remain explicit and lossless on disk.
- Added the plan-requested comment near vendor/product QEMU emission noting that flag syntax should be spot-checked with `qemu-system-x86_64 -device usb-host,help` before treating it as fully externally verified.
