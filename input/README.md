# Proxmox input files

This subdirectory contains input files that can be used as validation to check the proxmox import function

Directory structure:
- `<proxmox host name>/storage.cfg`: The proxmox storage configuration, needed to convert storage references
- `<proxmox host name>/<proxmox vmid>.conf`: The proxmox configuration, to be imported by ezkvm
- `<proxmox host name>/<proxmox vmid>.qemu.cmd`: The proxmox qemu command line, to be generated by ezkvm when starting the ezkvm config file that was created from the imported proxmox config file
- `<proxmox host name>/<proxmox vmid>.swtpm.cmd`: (if tpm was enabled) The proxmox swtpm command line, to be generated by ezkvm when starting the ezkvm config file that was created from the imported proxmox config file
- `<proxmox host name>/<proxmox vmid>.yaml`: (if a config was confirmed to be good) the resulting ezkvm config file generated from the imported proxmox file
