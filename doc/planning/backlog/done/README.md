# Completed Backlog Archive

This area is reserved for completed feature-centric backlog files and release-period archives.

Archive content expectations:
- include a completed-ticket table (ID/title, and when available completion date/notes)
- include short completion-detail notes summarizing what was delivered in that archive slice
- when practical, include full completed ticket definitions (status, dependencies, scope, acceptance criteria, and completion notes) to mirror active backlog detail depth
- keep any still-active continuation tickets in `../active/` and reference them from the done file

Suggested layout:
- `YYYY/A.md`
- `YYYY/B.md`
