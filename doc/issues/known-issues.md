# Known Issues Index

Use this file to track discoverable, recurring, or intentionally deferred issues.

## Entry Template

| ID | Title | Status | Severity | Workaround | Tracking Link |
|---|---|---|---|---|---|
| example | Short issue title | Open / Monitoring / Fixed | S0-S3 | Short workaround or `None` | Backlog ticket or planning file |

## Maintenance Rules

- Keep entries short and actionable.
- Link each issue to a backlog ticket or planning item when one exists.
- Remove or mark entries fixed when the underlying issue is resolved.
- Prefer this index for persistent discoverability, not for one-off transient debugging notes.
