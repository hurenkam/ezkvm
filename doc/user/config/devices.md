# Devices, Controllers, and Host Passthrough

## devices

### devices.drives

Common fields:

- `id` (optional, autogenerated)
- `path` (optional for cdrom, required for disk)
- `interface` (`virtio`, `scsi`, `ide`, `nvme`)
- `type` (`disk`, `cdrom`)
- `format`
- `readonly`
- optional advanced fields: `discard`, `ssd`, `controller`, `cache`, `aio`, `detect_zeroes`, `scsi_id`, `boot_index`, `bus`, `unit`

### devices.networks

Common fields:

- `id` (optional, autogenerated)
- `model`
- `backend` (structured backend)
- `mac`, `rx_queue_size`, `tx_queue_size`, `boot_index`, `bus`, `addr`

### devices.displays

- `type`
- optional `vram`

### devices.serials

- `type`
- optional `port`
- for tcp-like serials: `host`, `localaddr`, `localport`

### devices.input (canonical)

- list of input devices (`type`)

### devices.audio (canonical)

- audio device list (`type`, `id`, optional `bus`, `addr`, `cad`, `audiodev`)

## controllers (canonical)

### controllers.scsi

- entries match SCSI controller schema: `id`, `type`, optional `iothread`, `max_targets`, `bus`, `addr`

### controllers.xhci

- entries match XHCI schema: `id`, optional `p2`, `p3`, `bus`, `addr`

## host (canonical)

### host.pci

- VFIO devices: `device`, `id`, optional `pcie`, `x_vga`, `bus`, `addr`, `multifunction`, `romfile`

### host.usb

- USB passthrough: `id`, plus either `host` or both `hostbus` and `hostport`
- optional `bus`, `port`

## iscsi_disks

Top-level `iscsi_disks` list remains unchanged:

- `id`, `portal`, `target`
- optional `lun`, `initiator`, `username`, `password`, `controller`
